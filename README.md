## Featured projects

### [TaskFlow](https://github.com/PrathapKumarKatta/taskflow)
**Collaborative task management with workspace-level access control.**

Workspaces, projects, task assignments, comments, and activity history. Includes optimistic concurrency checks to prevent stale updates and background reminder workflows.

**Stack:** Python · FastAPI · PostgreSQL · SQLAlchemy · Redis · Celery · React · TypeScript

[Source code](https://github.com/PrathapKumarKatta/taskflow) · [Live application](https://taskflow-virid-three.vercel.app) · [API documentation](https://taskflow-virid-three.vercel.app/docs)

### [Codebase Intelligence](https://github.com/PrathapKumarKatta/CodeBase-Intelligence)
**Ask questions about a codebase and follow answers back to the source.**

Combines Tree-sitter syntax parsing, pgvector semantic search, and PostgreSQL full-text search. Answers include file and line citations with navigation in Monaco Editor. Background workers handle indexing.

**Stack:** Python · FastAPI · PostgreSQL · pgvector · Tree-sitter · Sentence Transformers · Redis · Celery · React

[Source code](https://github.com/PrathapKumarKatta/CodeBase-Intelligence) · [Architecture](https://github.com/PrathapKumarKatta/CodeBase-Intelligence/blob/main/docs/ARCHITECTURE.md)

### [AI Job Application Agent](https://github.com/PrathapKumarKatta/Ai-Resume-parser)
**Turn a résumé and job description into a tailored application package.**

A LangGraph workflow analyzes a résumé PDF, extracts job requirements, identifies skill gaps, and generates a cover letter and downloadable application package.

**Stack:** Python · Streamlit · LangGraph · Groq

[Source code](https://github.com/PrathapKumarKatta/Ai-Resume-parser)
